# One-Button Band

A musical playground where you combine drums, bass, keys, bells, trumpet, guitar, flute and shaker into a synchronized band. Add or remove instruments while they play, pause and resume the music, clear the band, or adjust and mute the volume.

One-button mode is enabled by default. A highlight moves between instruments and playback controls, letting you choose an action with Space or Enter, a compatible switch, or the large selection button. Space and Enter select the highlighted action without needing Tab, except while you are using a text field or preference input. The scanning speed is adjustable, and one-button mode can be deactivated. Instruments also support direct clicks and keyboard shortcuts.

The moving beat can be turned off. Music pauses when you leave the tab and waits for you to resume.

The melody editor opens by default and lets you choose an instrument, one of eight beats, and a note or rest using the same one-button scanning control. Drums offer kick, snare and hi-hat hits; shaker offers a hit or rest. Keep any beat's original phrase, preview changes with the band, undo edits, or reset an instrument's melody. Editing pauses the music, and melody changes are saved in this browser.
